# 大學特殊選才落點探索與數據導航系統 (Special Admission Navigator)

這是一套為台灣升大學「**特殊選材**」考生與家長量身打造的**條件落點配對、名額歷史趨勢追蹤與簡章數據管理平台**。

收錄近三年（**112、113、114 學年度**）全台頂尖大學、中字輩、師範與優質私校之指標校系，涵蓋：
* **跨領域全校不分系**（清大拾穗、交大百川、成大全校不分系、政大傳播等）
* **資訊 / 資安 / 電資學群**（台大資工、交大資工APCS/資安組、成大、中央、中正、師大等）
* **基礎數理化與科學學群**（台大數學/化學、清大理學院、交大應數、師大物理等）
* **人文社會、外語與傳播學群**（政大東南亞/阿文、中興中文、東吳法律、師大人社等）
* **藝術設計與建築學群**（北藝大新媒體、成大建築、實踐服裝等）
* **生醫農學**（台大生科、長庚醫檢等）

## 🌟 核心功能說明

### 1. 🎯 條件適配度媒合引擎 (Fit Score Matcher)
* **左側條件面板**：輸入您的真實條件，包含：
  * **個人背景資歷**：一般生、非學校型態實驗教育、自學生、經濟弱勢/願景計畫、新住民子女、境外台生。
  * **APCS 級分**：觀念題 (0~5級) 與 實作題 (0~5級)。
  * **特殊競賽獲獎**：奧林匹亞、科展/TISF、旺宏獎、資訊學科能力競賽、資安CTF、文學獎、高中辯論/模聯、專利創業。
  * **語文檢定**：多益金色 (860+)、雅思 6.5+、日檢 N2/N1、罕見語種能力。
* **適配度評分（%）**：系統自動比對各校系門檻與偏好，為每個科系計算出契合度分數（**80%以上高度契合** / **65~79%具競爭力** / **65%以下可挑戰**）。

### 2. 📊 近三年名額趨勢圖表
* 每個卡片均展示 **112年 ➔ 113年 ➔ 114年** 最新招收名額演變。
* 自動標註名額增加（如 `⬆ 增加 4 席`）或持平狀態，方便快速掌握哪些校系正在擴增特選名額（如資安外加、跨領域學程）。

### 3. 🔍 簡章深度拆解與評審視角
* 點擊卡片上的「**簡章與錄取分析**」，即可開啟詳細視窗：
  * 完整評分比例（書面審查 % ｜ 口試 % ｜ 現場筆試或上機實作 %）。
  * 資格門檻與 APCS 建議分數。
  * **歷屆錄取核心策略**：由過往經驗解析教授偏好的專長類型、面試防守要點與白板解題建議。
  * 官方專屬連結：一鍵直達各大學特選招生專頁。

### 4. ⚖️ 橫向對比與志願收藏清單
* 點擊卡片上的「**＋對比**」：可同時選取最多 4 所校系，進行一對一規格比較（名額、評分佔比、門檻條件）。
* 點擊「**☆ 收藏**」：加入個人目標清單，支援**一鍵複製純文字清單**或**匯出為 JSON 設定檔**。

## 📁 檔案結構說明

* `index.html`：系統主頁面（整合側邊欄、卡片網格、對比與詳情彈跳視窗）。
* `style.css`：現代化響應式介面樣式（卡片、名額條、標籤、色彩系統）。
* `app.js`：前端互動邏輯、即時篩選、契合度計分演算法、收藏與對比管理器。
* `data.js`：內建 112～114 學年度全台指標校系完整資料庫。
* `admission_data.json`：標準 JSON 格式數據庫，便於其他程式或爬蟲串接。
* `admission_summary.csv`：可直接用 Excel 或 Google 試算表開啟的整理表格。
* `collector.py`：資料驗證、格式轉換與統計分析工具。
